POST

/api/dl

Media Extractor

Mengekstrak metadata media lengkap, URL file direct stream (MP4/MP3), resolusi, thumbnail, foto slide/carousel, dan link download dari tautan TikTok dan Instagram yang dikirimkan.

Request Headers & Payload

Parameter Tipe Keterangan
url Wajib string Tautan URL media target yang ingin diekstrak (TikTok video/slide atau Instagram reel/post/story).

Contoh Kode Integrasi (Code Snippets)

curl -X POST "https://devils-sigma.vercel.app/api/dl" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://www.tiktok.com/@inidenjiww/video/738291029102"}'
GET

/api/stream

Proxy Stream Relay

Melakukan streaming relay direct playback untuk memintas CORS policy, header referer, atau batasan hotlinking pada pemutar video HTML5 dan aplikasi pihak ketiga.

Query Parameters

Parameter Tipe Keterangan
url Wajib string Direct stream URL yang akan di-relay melalui proxy server.
ref Opsional string Custom HTTP Referer header yang dikirimkan ke target server.

Contoh Kode Integrasi

curl "https://devils-sigma.vercel.app/api/stream?url=https%3A%2F%2Fmp4-06.overfetch.video%2FvMVlX9VsHp%2Fmaster.mp4"

HTTP Status Codes Reference

Error Handling Standards
200 OK
Sukses Permintaan berhasil diproses dan media berhasil diekstrak secara akurat.
400 Bad Request
Parameter Kurang Body JSON tidak memiliki properti url yang valid.
422 Unprocessable
Ekstraksi Gagal Tautan media diproteksi, privat, atau tidak didukung oleh extractor.
500 Server Error
Internal Error Terjadi kendala pada upstream stream gateway atau serverless timeout.
