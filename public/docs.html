Authentication

API ini bersifat Public & Open. Anda tidak memerlukan API key atau autentikasi khusus untuk melakukan permintaan unduhan maupun streaming. Header CORS diaktifkan secara global (Access-Control-Allow-Origin: *).

Endpoints Reference

POST /api/dl

Mengekstrak metadata lengkap, cover, avatar, audio musik MP3, serta daftar tautan unduhan HD langsung dari TikTok, Instagram, Foto Live, atau Aliran Video Universal.

Parameter Type Position Keterangan
url string REQUIRED Body / Query Tautan media publik (TikTok, Instagram, atau video langsung). 
curl -X POST https://your-domain.com/api/dl \
  -H "Content-Type: application/json" \
  -d '{"url": "https://vt.tiktok.com/ZSbSH1Myk/"}'
const res = await fetch('https://your-domain.com/api/dl', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ url: 'https://vt.tiktok.com/ZSbSH1Myk/' })
});
const data = await res.json();
console.log(data);
import requests

url = "https://your-domain.com/api/dl"
payload = {"url": "https://vt.tiktok.com/ZSbSH1Myk/"}
response = requests.post(url, json=payload)
data = response.json()
print(data)
GET /api/stream

Streaming proxy berkecepatan tinggi dengan dukungan HTTP Range (206 Partial Content) untuk video seeking instan dan bypass hotlink protection.

Parameter Type Position Keterangan
url string REQUIRED Query URL aliran video langsung yang akan di-stream.
ref string OPTIONAL Query Domain referer yang dibutuhkan oleh upstream CDN.
dl string OPTIONAL Query Kirim nilai 1 untuk memaksa browser mengunduh sebagai file lampiran. 
curl -I "https://your-domain.com/api/stream?url=https%3A%2F%2Fexample.com%2Fvideo.mp4&dl=1"
GET /api/profile

Mengambil informasi profil, tautan bio, serta akun sosial media.

curl https://your-domain.com/api/profile
GET /api/health

Cek status kesehatan server, uptime, dan timestamp saat ini.

curl https://your-domain.com/api/health

Error Handling & Status Codes

Status Code Status Deskripsi
200 OK success Permintaan berhasil diproses dan data media berhasil diekstrak.
400 Bad Request error Parameter URL tidak disertakan atau format JSON tidak valid.
500 Internal Error error Gagal memproses tautan media (konten privat, dihapus, atau tidak ditemukan).
