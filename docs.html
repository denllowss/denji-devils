            GET
            
/api/stream

            
          

          

            
            Proxy Stream Relay
          

        


        

          Relay streaming direct playback untuk memintas CORS policy, header referer, dan batasan hotlinking pada pemutar video HTML5 maupun aplikasi pihak ketiga. Mendukung HTTP Range sehingga video bisa di-seek.
        


        

          

            

              
Query Parameters

              

                

                  
                    
ParameterTipeKeterangan

                  
                  
                    

                      urlWajib
                      string
                      Direct stream URL yang akan di-relay. Wajib di-encodeURIComponent.
                    

                    

                      refOpsional
                      string
                      Custom HTTP Referer yang dikirim ke server target. Default https://vidmonstr.com/.
                    

                    

                      dlOpsional
                      string
                      Isi 1 untuk memaksa header Content-Disposition: attachment (unduh, bukan putar).
                    

                    

                      titleOpsional
                      string
                      Nama file saat dl=1. Ekstensi .mp4 ditambahkan otomatis.
                    

                  
                

              

            


            

              
Respons

              

                Respons bukan JSON, melainkan binary stream yang diteruskan apa adanya dari server asal.
              

              

                

                  
                    
HeaderNilai

                  
                  
                    
Content-Typevideo/mp4 (mengikuti server asal)

                    
Accept-Rangesbytes — mendukung seek / partial request

                    
Cache-Controlpublic, max-age=86400

                    
Access-Control-Allow-Origin*

                  
                

              

              
    
                
  • Endpoint /api/proxy adalah alias dengan perilaku yang sama persis.
    • 
                
  • Gunakan parameter ref bila CDN target menolak request tanpa referer yang sesuai.

            GET
            
/iqc

            
          

          

            
            Quote Card · JPG
          

        


        

          Mengubah teks menjadi foto JPG berupa tangkapan layar obrolan Instagram DM — lengkap dengan emoji gaya iPhone, wallpaper percakapan blur acak, jam WIB otomatis, dan indikator baterai.
        


        

          

            

              
Query Parameters

              

                

                  
                    
ParameterTipeKeterangan

                  
                  
                    

                      pesanOpsional
                      string
                      Isi bubble chat. Mendukung emoji dan baris baru, maksimal 1000 karakter, aman dari XSS.
                    

                    

                      modeOpsional
                      string
                      dark untuk tampilan gelap, light memaksa terang. Kosongkan untuk terang.
                    

                    

                      seedOpsional
                      number
                      Angka bulat — wallpaper dan level baterai (30–100%) terkunci sesuai seed; jam tetap mengikuti WIB.
                    

                    

                      nameOpsional
                      string
                      Nama pada kartu (khusus v2). Maksimal 30 karakter, default Jidar.
                    

                    

                      v2Opsional
                      string
                      1 = versi menu konteks WhatsApp. Sama dengan memanggil /iqc2.
                    

                  
                

              

              

                1350x2400 px
                kualitas 90
                emoji Apple
                jam WIB
                wallpaper acak
              

            


            

              
Respons

              

                Bukan JSON — endpoint membalas image/jpeg berukuran 1350×2400 piksel (rasio 9:16, kualitas 90).
              

              

                

                  
                    
HeaderNilai

                  
                  
                    
Content-Typeimage/jpeg

                    
Cache-Controlno-store — browser/CDN tidak menyimpan respons, termasuk saat memakai seed

                    
X-Content-Type-Optionsnosniff

                  
                

              

              
    
                
  • Gambar dirender headless Chromium (puppeteer-core + @sparticuz/chromium) — request pertama dapat lebih lambat karena cold start browser.
    • 
                
  • Tanpa seed, wallpaper & baterai diacak. Dengan seed, server memakai cache memori per menit WIB; header tetap no-store.
    • 
                
  • Emoji umum (❤ 😂 🔥 💯 🙏) tertanam di template; emoji langka diunduh dari CDN saat render dengan fallback ke teks.
    • 
                
  • Bila render gagal total, endpoint tetap membalas gambar — foto "gagal membuat gambar" dengan status 500.
    • 
                
  • Jika gagal, periksa header X-IQC-Error-Code. Renderer memakai Chromium yang kompatibel dengan Node 24/Vercel dan mengekstrak library NSS sebelum launch.
    • 
                
  • Alias API: /api/iqc dan /api/iqc2. Buka editor IQC untuk mengubah teks dan mengunduh JPG.
    •

            iMessage · Music JPG
          

        


        

          Quote iMessage × Apple Music dari foto referensi: lirik, nama musik, artis, gradient/solid, dan waktu bisa diubah. Tanpa parameter, hasil memakai foto asli yang identik. Setelah diedit, tinggi kartu dan gambar mengikuti teks secara otomatis.
        


        

          

            

              
Query Parameters

              

                

                  
                    
ParameterTipeKeterangan

                  
                  
                    
lirikOpsionalstringIsi lirik/pesan, maksimal 1000 karakter. Baris baru didukung. Alias: lyrics / pesan.

                    
musicOpsionalstringNama musik, maksimal 100 karakter. Default Good Days. Alias: judul / title / lagu.

                    
artistOpsionalstringNama artis, maksimal 100 karakter. Default SZA. Alias: artis.

                    
bgOpsionalstringgradient (default) atau solid. Yang diubah adalah latar kartu lirik, bukan latar layar blur.

                    
color1 / color2OpsionalhexDua warna gradient. Gunakan enam digit hex, mis. 2e617b dan 312553; tanda # boleh digunakan jika di-URL-encode.

                    
colorOpsionalhexWarna untuk mode solid, mis. 1f4260.

                    
angleOpsionalnumberArah gradient 0–360 derajat, default 135.

                    
timeOpsionalstringLabel waktu di kartu (maks. 10 karakter), default 0:03.

                    
htmlOpsionalstring1 untuk template HTML/pratinjau. Kosongkan untuk foto JPG.

                  
                

              

              
736 px lebartinggi otomatisgradient / solidfoto referensi

            


            

              
Respons

              

                Sukses membalas image/jpeg, lebar 736 px, tinggi minimal 1308 px. Teks panjang memperbesar tinggi hasil tanpa dipotong. Jika gagal, respons berupa JSON dengan status 500.
              

              

                

                  
                    
HeaderNilai

                  
                  
                    
Content-Typeimage/jpeg

                    
Cache-Controlno-store — browser/CDN tidak menyimpan respons, termasuk saat memakai seed

                    
X-Content-Type-Optionsnosniff

                  
                

              

              
    
                
  • Default menggunakan JPEG asli, bukan menggambar ulang font/ikon. Setelah teks atau warna diubah, komponennya dirender dinamis mengikuti layout foto.
    • 
                
  • Reaksi dan menu memakai asset dari foto referensi. Judul/artis panjang dapat membungkus ke beberapa baris.
    • 
                
  • Untuk #2e617b, tulis %232e617b di URL atau gunakan URLSearchParams. Lebih praktis memakai hex tanpa tanda #.
    • 
                
  • Alias /api/iqc3. Buka editor IQC3 untuk pratinjau langsung, pemilih warna, dan unduh JPG.
    • 
                
  • Gambar statis: tombol play dan nama musik tidak memutar audio. Kode kegagalan aman ada pada header X-IQC-Error-Code.

            REF
            
HTTP Status Codes

          

          Error Handling
        


        

          Periksa status HTTP dan Content-Type: downloader membalas JSON, proxy dapat membalas teks, sedangkan IQC tetap membalas gambar fallback saat render gagal.
        


        

          

            
200 OK

            Sukses
            Permintaan berhasil diproses. Format hasil mengikuti endpoint: JSON, stream media, atau JPG.
          

          

            
400 Bad Request

            Parameter Kurang
            Parameter url yang diperlukan belum diisi pada body/query.
          

          

            
500 Server Error

            Pemrosesan Gagal
            Ekstraksi media gagal, atau render IQC gagal. IQC mengirim gambar fallback dengan status ini.
          

          

            
502 Bad Gateway

            Upstream Error
            Server sumber media tidak bisa dihubungi — umumnya pada /api/stream.
          

        

      


      

        Endpoint tidak ditemukan
        Coba kata kunci lain seperti /api/dl, stream, health, profile, atau iqc.
