Headers & cara pakai IQC1–5 / SSGC
GET IQC tanpa body JSON; baca respons sebagai gambar/blob/binary. IQC1–4 memakai JPG; IQC5 default PNG dan mendukung format=jpg. SSGC default JPG asli; format=png tersedia. Deskripsi SSGC mengikuti limit / full. Untuk profil upload IQC5 / SSGC gunakan POST multipart dengan field profile, jangan menetapkan boundary sendiri di browser. URL/kode Playground mengikuti semua input, dan preview/unduh memakai satu respons.
HeaderModelArti / kapan tersedia
Content-TypeIQC1–5image/jpeg; khusus IQC5 default image/png. Error IQC3–5 memakai application/json. IQC1/2 dapat mengirim JPEG fallback dengan HTTP error.
Content-LengthIQC1–5Jumlah byte respons gambar, bukan jumlah karakter pesan. Header transport dapat berbeda pada respons error/HTML.
Content-DispositionIQC1–5inline; filename=... untuk gambar. Playground memilih nama unduhan sesuai model dan format.
Cache-ControlIQC1–5no-store: respons tidak disimpan browser/CDN. Cache renderer IQC1/2 terpisah dari cache HTTP.
X-Content-Type-OptionsIQC1–5nosniff; browser tidak menebak tipe file.
X-IQC-VariantIQC1–5Nomor model 1–5; tersedia pada request model yang valid.
X-IQC-RendererIQC1–5chromium-153-node24; runtime renderer project.
X-IQC-WidthIQC1–5Lebar gambar yang benar-benar dikirim, dalam px.
X-IQC-HeightIQC1–5Tinggi gambar yang benar-benar dikirim. IQC3–5 bertambah untuk teks panjang.
X-IQC-Error-CodeIQC1–5Hanya jika ada error. Periksa bersama HTTP status; gambar fallback tidak berarti sukses.
Access-Control-Allow-OriginIQC1–5*; API dapat dipanggil dari origin lain.
Access-Control-Allow-MethodsIQC1–5IQC1–4: GET, HEAD, OPTIONS. IQC5 juga POST untuk profil upload.
Access-Control-Expose-HeadersIQC1–5Daftar header yang boleh dibaca JavaScript melalui CORS; mencakup metadata gambar di atas.
AllowIQC1–5Hanya pada HTTP 405, menunjukkan metode yang didukung.
X-IQC-CacheIQC1 / IQC2HIT / MISS. Seed eksplisit memakai cache per menit WIB; jam di gambar tetap WIB.
X-IQC-SourceIQC3 / IQC4reference-photo (default) / dynamic-render (hasil edit).
X-IQC-SourceIQC5reference-photo (PNG asli), reference-converted (default JPG), dynamic-render (hasil edit).
Access-Control-Allow-HeadersIQC5Content-Type; mendukung POST profil multipart / JSON / image body.

Content-LengthSSGCUkuran respons gambar dalam byte.
Content-DispositionSSGCinline; filename=ssgc.jpg / ssgc.png.
Cache-ControlSSGCno-store.

X-SSGC-VariantSSGCgroup-info.
X-SSGC-RendererSSGCchromium-153-node24.

            Proxy Stream Relay
          

        


        

          Relay streaming direct playback untuk memintas CORS policy, header referer, dan batasan hotlinking pada pemutar video HTML5 maupun aplikasi pihak ketiga. Mendukung HTTP Range sehingga video bisa di-seek.
        


        

          

            

              
Query Parameters

              

                

                  
                    
ParameterTipeKeterangan

                  
                  
                    

                      urlWajib
                      string
                      Direct stream URL yang akan di-relay. Wajib di-encodeURIComponent.
                    

                    

                      refOpsional
                      string
                      Custom HTTP Referer yang dikirim ke server target. Default https://vidmonstr.com/.
                    

                    

                      dlOpsional
                      string
                      Isi 1 untuk memaksa header Content-Disposition: attachment (unduh, bukan putar).
                    

                    

                      titleOpsional
                      string
                      Nama file saat dl=1. Ekstensi .mp4 ditambahkan otomatis.

Respons

              

                Bukan JSON — endpoint membalas image/jpeg berukuran 1350×2400 piksel (rasio 9:16, kualitas 90).
              

              

                

                  
                    
HeaderNilai

                  
                  
                    
Content-Typeimage/jpeg

                    
Cache-Controlno-store — browser/CDN tidak menyimpan respons, termasuk saat memakai seed

                    
X-Content-Type-Optionsnosniff

                  
                

              

              
    
                
  • Gambar dirender headless Chromium (puppeteer-core + @sparticuz/chromium) — request pertama dapat lebih lambat karena cold start browser.
    • 
                
  • Tanpa seed, wallpaper & baterai diacak. Dengan seed, server memakai cache memori per menit WIB; header tetap no-store.
    • 
                
  • Emoji umum (❤ 😂 🔥 💯 🙏) tertanam di template; emoji langka diunduh dari CDN saat render dengan fallback ke teks.
    • 
                
  • Bila render gagal total, endpoint tetap membalas gambar — foto "gagal membuat gambar" dengan status 500.
    • 
                
  • Jika gagal, periksa header X-IQC-Error-Code. Renderer memakai Chromium yang kompatibel dengan Node 24/Vercel dan mengekstrak library NSS sebelum launch.
    • 
                
  • Alias API: /api/iqc dan /api/iqc2. Buka editor IQC untuk mengubah teks dan mengunduh JPG.

200 OK

            Sukses
            Permintaan berhasil diproses. Format hasil mengikuti endpoint: JSON, stream media, atau JPG.

            Parameter Kurang
            Parameter url yang diperlukan belum diisi pada body/query.
          

          

            
500 Server Error

            Pemrosesan Gagal
            Ekstraksi media gagal, atau render IQC gagal. IQC mengirim gambar fallback dengan status ini.

            Server sumber media tidak bisa dihubungi — umumnya pada /api/stream.
