/api/dl

Media Extractor

Mengekstrak metadata media lengkap, URL direct stream (MP4/MP3), thumbnail, foto slide/carousel, dan link unduhan dari tautan TikTok maupun Instagram. Platform dideteksi otomatis dari URL yang dikirim.

Parameter Request

Kirim lewat POST body JSON, atau cukup GET dengan query ?url=... untuk pemakaian cepat.

ParameterLokasiTipeKeterangan
urlWajib body / query string Tautan media target: video & slide TikTok, reel/post/story Instagram, atau direct link .mp4/.m3u8.
Content-TypeHeader header string Wajib application/json bila mengirim body JSON pada metode POST.
tiktok.com vt.tiktok.com instagram.com/reel instagram.com/p instagram.com/stories *.mp4 / *.m3u8

Field Respons

FieldTipeKeterangan
statusstringsuccess atau error.
codenumberSalinan HTTP status code.
platformstringtiktok, instagram, atau video.
sourcestringEngine yang dipakai, misal tikwm, lovetik, ssstik, snapsave, videodropper.
typestringvideo · image · live_photo · carousel · story · folder.
idstring | nullID media dari platform asal.
titlestringJudul atau caption media.
coverstring | nullURL thumbnail / cover.
durationnumber | nullDurasi dalam detik (TikTok).
authorobject{ id, name, username, avatar }.
downloadsobject{ video, video_hd, video_watermark, audio, photos[], live_photos[], media[] }.
statsobject{ likes, comments, shares, views, downloads } — TikTok via tikwm.

Catatan Pemakaian

  • Postingan harus bersifat publik — akun privat atau media berbayar tidak dapat diekstrak.
  • Gunakan field downloads.video_hd untuk kualitas terbaik; fallback ke downloads.video bila null.
  • Slide/carousel mengisi downloads.photos[] dan downloads.media[]; video tunggal mengisi downloads.video.
  • Semua URL direct stream bisa di-relay lewat /api/stream bila terblokir CORS/hotlink.

/api/stream

            
          

          

            
            Proxy Stream Relay
          

        


        

          Relay streaming direct playback untuk memintas CORS policy, header referer, dan batasan hotlinking pada pemutar video HTML5 maupun aplikasi pihak ketiga. Mendukung HTTP Range sehingga video bisa di-seek.
        


        

          

            

              
Query Parameters

              

                

                  
                    
ParameterTipeKeterangan

                  
                  
                    

                      urlWajib
                      string
                      Direct stream URL yang akan di-relay. Wajib di-encodeURIComponent.
                    

                    

                      refOpsional
                      string
                      Custom HTTP Referer yang dikirim ke server target. Default https://vidmonstr.com/.
                    

                    

                      dlOpsional
                      string
                      Isi 1 untuk memaksa header Content-Disposition: attachment (unduh, bukan putar).
                    

                    

                      titleOpsional
                      string
                      Nama file saat dl=1. Ekstensi .mp4 ditambahkan otomatis.
                    

                  
                

              

            


            

              
Respons

              

                Respons bukan JSON, melainkan binary stream yang diteruskan apa adanya dari server asal.

Accept-Rangesbytes — mendukung seek / partial request

                    
Cache-Controlpublic, max-age=86400

                    
Access-Control-Allow-Origin*

            GET
            
/iqc

            
          

          

            
            Quote Card · JPG
          

        


        

          Mengubah teks menjadi foto JPG berupa tangkapan layar obrolan Instagram DM — lengkap dengan emoji gaya iPhone, wallpaper percakapan blur acak, jam WIB otomatis, dan indikator baterai.
        


        

          

            

              
Query Parameters

              

                

                  
                    
ParameterTipeKeterangan

                  
                  
                    

                      pesanOpsional
                      string
                      Isi bubble chat. Mendukung emoji dan baris baru, maksimal 1000 karakter, aman dari XSS.
                    

                    

                      modeOpsional
                      string
                      dark untuk tampilan gelap, light memaksa terang. Kosongkan untuk terang.
                    

                    

                      seedOpsional
                      number
                      Angka bulat — wallpaper dan level baterai (30–100%) terkunci sesuai seed; jam tetap mengikuti WIB.
                    

                    

                      nameOpsional
                      string
                      Nama pada kartu (khusus v2). Maksimal 30 karakter, default Jidar.
                    

                    

                      v2Opsional
                      string
                      1 = versi menu konteks WhatsApp. Sama dengan memanggil /iqc2.
                    

                  
                

              

              

                1350x2400 px
                kualitas 90
                emoji Apple
                jam WIB
                wallpaper acak
              

            


            

              
Respons

              

                Bukan JSON — endpoint membalas image/jpeg berukuran 1350×2400 piksel (rasio 9:16, kualitas 90).
              

              

                

                  
                    
HeaderNilai

                  
                  
                    
Content-Typeimage/jpeg

                    
Cache-Controlno-store — browser/CDN tidak menyimpan respons, termasuk saat memakai seed

                    
X-Content-Type-Optionsnosniff

                  
                

              

              
    
                
  • Gambar dirender headless Chromium (puppeteer-core + @sparticuz/chromium) — request pertama dapat lebih lambat karena cold start browser.
    • 
                
  • Tanpa seed, wallpaper & baterai diacak. Dengan seed, server memakai cache memori per menit WIB; header tetap no-store.
    • 
                
  • Emoji umum (❤ 😂 🔥 💯 🙏) tertanam di template; emoji langka diunduh dari CDN saat render dengan fallback ke teks.
    • 
                
  • Bila render gagal total, endpoint tetap membalas gambar — foto "gagal membuat gambar" dengan status 500.
    • 
                
  • Alias API: /api/iqc dan /api/iqc2. Buka editor IQC untuk mengubah teks dan mengunduh JPG.

            REF
            
HTTP Status Codes

          

          Error Handling
        


        

          Periksa status HTTP dan Content-Type: downloader membalas JSON, proxy dapat membalas teks, sedangkan IQC tetap membalas gambar fallback saat render gagal.
        


        

          

            
200 OK

            Sukses
            Permintaan berhasil diproses. Format hasil mengikuti endpoint: JSON, stream media, atau JPG.
          

          

            
400 Bad Request

            Parameter Kurang
            Parameter url yang diperlukan belum diisi pada body/query.
          

          

            
500 Server Error

            Pemrosesan Gagal
            Ekstraksi media gagal, atau render IQC gagal. IQC mengirim gambar fallback dengan status ini.
          

          

            
502 Bad Gateway

            Upstream Error
            Server sumber media tidak bisa dihubungi — umumnya pada /api/stream.
          

        

      


      

        Endpoint tidak ditemukan
        Coba kata kunci lain seperti /api/dl, stream, health, profile, atau iqc.
